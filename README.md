# Mohammad

I build apps, program robots, and experiment with AI. This GitHub has a mix of those projects and smaller tools.

A few places to start:

- [Unplugged](https://github.com/MohammadSyed18/Unplugged) — a focus app in React Native / Expo.
- [BridgeAI](https://github.com/MohammadSyed18/BridgeAI) and [LocalLens](https://github.com/MohammadSyed18/LocalLens) — working with school announcements and community notices.
- [Vanguard26](https://github.com/MohammadSyed18/Vanguard26/tree/Vanguard2/TeamCode/src/main/java/org/firstinspires/ftc/teamcode) — our FTC robot's Java code.
- [ARISE](https://github.com/MohammadSyed18/ARISE-experiment) — experiments with claims, evidence, and revisions. The current adapter is rule-based.
- [PlannerAI](https://github.com/MohammadSyed18/PlannerAI) — task scheduling in C++.

There are also routing experiments in [AccessPath](https://github.com/MohammadSyed18/AccessPath), Arabic-reading practice tools in [QaidahCoach](https://github.com/MohammadSyed18/QaidahCoach), and smaller Java, Python, and Go utilities in the repositories.

I use VS Code, PyCharm, Android Studio, Git, and Figma. The code here shows different parts of that work; some projects use sample data or are still prototypes. Their READMEs explain what runs and what's unfinished.
